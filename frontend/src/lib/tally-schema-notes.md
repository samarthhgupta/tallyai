# Tally Prime XML Schema Reference Notes

## Source
All schema patterns extracted from live Tally Prime exports from "Kapra Kothi Emporium FY 2026-27 - (from 1-Apr-26)".

---

## General Import File Format
- No `<?xml version...?>` declaration in Tally's own exports (but UTF-8 with declaration is accepted for import)
- File structure:
```xml
<ENVELOPE>
  <HEADER><TALLYREQUEST>Import Data</TALLYREQUEST></HEADER>
  <BODY>
    <IMPORTDATA>
      <REQUESTDESC>
        <REPORTNAME>All Masters</REPORTNAME>
        <STATICVARIABLES>
          <SVCURRENTCOMPANY>EXACT company name as shown in Tally</SVCURRENTCOMPANY>
        </STATICVARIABLES>
      </REQUESTDESC>
      <REQUESTDATA>
        <!-- TALLYMESSAGE blocks -->
      </REQUESTDATA>
    </IMPORTDATA>
  </BODY>
</ENVELOPE>
```

**CRITICAL**: `SVCURRENTCOMPANY` must exactly match the company name open in Tally (including FY suffix if present).

### HSNDETAILS.LIST
```xml
<HSNDETAILS.LIST>
  <APPLICABLEFROM>20180401</APPLICABLEFROM>
  <HSNCODE>63049290</HSNCODE>   <!-- 8-digit HSN from stock_items table -->
  <SRCOFHSNDETAILS>Specify Details Here</SRCOFHSNDETAILS>
</HSNDETAILS.LIST>
```

**Implementation notes:**
- `APPLICABLEFROM` should be the FY start date (e.g. `20240401` for FY 2024-25)
- CGST rate = SGST rate = total_gst_percent / 2
- IGST rate = total_gst_percent
- `hsn` column in `stock_items` table holds the HSN code
- `gst_percent` column holds the total GST rate
- When `gst_percent` is null/0, omit GSTDETAILS.LIST or set TAXABILITY to Exempt/Nil Rated
